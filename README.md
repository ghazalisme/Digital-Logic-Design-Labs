# Digital Logic Design – Laboratory Exercises

A collection of practical laboratory exercises focused on the design, implementation, and simulation of digital logic circuits using **Proteus Design Suite**.

This repository contains academic exercises completed as part of the Digital Logic Design coursework. It covers fundamental concepts in combinational and sequential logic circuits, including arithmetic circuits, flip-flops, counters, and shift registers.

The primary goal of this repository is to document practical implementations of digital logic concepts and demonstrate their behavior through circuit simulation.

## Overview

Digital Logic Design is a fundamental subject in computer engineering that focuses on the design and analysis of digital systems.

This repository provides practical implementations of various digital circuits, starting with basic logic components and progressing toward more advanced sequential and combinational circuits.

Each exercise is organized in its own directory to make the projects easy to navigate, review, and execute.

## How to Run the Projects

To explore and run the circuit simulations:

1. Clone or download this repository.
2. Install Proteus Design Suite.
3. Navigate to the desired exercise directory.
4. Locate and open the corresponding Proteus project file.
5. Run the simulation to observe the circuit behavior.

**Note:** Some exercises may require additional project files or libraries depending on their implementation.
